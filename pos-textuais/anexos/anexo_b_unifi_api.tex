% ----------------------------------------------------------
\chapter{Endpoints da API do UniFi Controller}
\label{an:api_unifi}
% ----------------------------------------------------------

Este anexo descreve os principais endpoints HTTP REST e chaves de dados expostos pela controladora central Ubiquiti UniFi, que foram consultados periodicamente pelo coletor ativo da UFOP para consolidar as estatísticas dos clientes em tempo de execução.

\begin{table}[htb]
\IBGEtab{%
  \caption{Endpoints da API REST Utilizados na Coleta UniFi}%
  \label{tab:endpoints_api_unifi}%
}{%
  \resizebox{\textwidth}{!}{%
    \begin{tabular}{lll}
      \toprule
      Método HTTP & Endpoint REST da Controladora & Descrição e Propósito da Coleta \\
      \midrule
      \texttt{POST} & \texttt{/api/login} & Autenticação e aquisição do cookie de sessão \\
      \texttt{GET} & \texttt{/api/s/default/stat/sta} & Telemetria em tempo real de clientes conectados \\
      \texttt{GET} & \texttt{/api/s/default/stat/device} & Status operacional, canais e nomes dos Access Points \\
      \texttt{POST} & \texttt{/api/logout} & Encerramento e expiração da sessão de API \\
      \bottomrule
    \end{tabular}%
  }%
}{%
  \fonte{Ubiquiti Networks UniFi API Documentation.}%
}
\end{table}
